HOW IT WORKS

Nothing here reads DNA. Here's what actually happens at each step.

A genetic relationship result is only as trustworthy as the process behind it. GeneMatch is deliberately explicit about which steps are laboratory science and which are software, so nothing gets blurred together.

  1. STEP 01

    Sample collection

    A trained collector takes a biological sample, such as a buccal swab or blood draw, under a documented consent process. The sample receives a unique ID and enters chain-of-custody tracking immediately.

  2. STEP 02

    Laboratory processing

    The laboratory extracts DNA and processes it using validated testing, genotyping, or sequencing equipment. This is the only step where DNA is actually read. GeneMatch has no role here.

  3. STEP 03

    Secure data transfer

    The instrument output is transferred to GeneMatch through an authenticated import channel or instrument adapter, and validated against the expected format before anything is stored.

  4. STEP 04

    Quality control

    Every imported profile is checked for missing markers, invalid values, and sample mismatches before it can be compared. A failed check blocks analysis until a reviewer resolves it.

  5. STEP 05

    Comparison & statistical analysis

    GeneMatch compares the profiles marker by marker and applies the statistical methodology appropriate to the relationship being tested, using established scientific methods rather than a single invented score.

  6. STEP 06

    Scientific review

    A qualified analyst reviews the statistical result before it can be reported. Software never issues a result without a reviewer in the loop.

  7. STEP 07

    Report

    A report is generated stating the method, markers analyzed, statistical result, limitations, and reviewer, with a verification code a third party can check against the system of record.

A note on language

You'll see "consistent with" rather than "proves" throughout GeneMatch reports. Genetic evidence is statistical. A result states what the data is consistent with under a specified set of assumptions, not an absolute certainty.
